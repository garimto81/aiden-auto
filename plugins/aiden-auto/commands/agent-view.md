# /agent-view — 백그라운드 작업 상태 보기

여러 작업을 동시에 돌리고 있을 때, 지금 누가 무엇을 하고 있는지 한눈에 봅니다.

## 비유

식당 본점이 분점 여러 곳에 일을 시킨 상태. 분점들이 지금 무엇을 하고 있는지 본점에서 확인하는 화면.

## 사용

```
/agent-view              ← 전체 백그라운드 작업 목록
/agent-view {id}         ← 특정 작업 자세히
/agent-view --logs {id}  ← 작업 로그 보기
```

내부적으로 공식 `claude agents` CLI를 호출합니다.

## 4-Mode 운영 패턴 (자율 판단)

| 모드 | 언제 | 화면 비유 |
|------|------|----------|
| **Split** | 분점들이 각자 다른 영역 담당 | 4분할 모니터 |
| **Blocked** | 다른 작업 끝나기를 기다림 | 빨간 신호등 |
| **Conflict** | 같은 파일을 두 분점이 동시 수정 | 두 셰프가 같은 냄비 |
| **Watch** | 본점이 분점 상태만 지켜봄 | CCTV 모드 |

Claude가 자동으로 적절한 모드 판단. 사용자는 결과만 확인.

## 관련 도구

| 명령 | 역할 |
|------|------|
| `claude agents` | 백그라운드 세션 spawn (별도 OS 프로세스) |
| `claude --bg "<task>"` | 단일 백그라운드 작업 시작 |
| `claude logs <id>` | 특정 작업의 로그 확인 |
| `claude respawn --all` | 컴퓨터 재부팅 후 모든 작업 일괄 재시작 |
