# TL;DR — 한 줄 결론

아직 원인을 단정할 수 없습니다. 다만 "어제 배포"와 "어제부터 502"가 시간상 겹치므로, **이번 배포가 새 앱을 제대로 못 띄워서 안내 서버가 빈손으로 돌아온 것**이 가장 유력합니다. 확정하려면 로그 몇 가지가 필요합니다.

## 무슨 일이 있었나

사이트를 새로 배포한 뒤, 어제부터 페이지를 열면 502 오류가 뜬다고 하셨습니다.
502는 "손님을 맞는 안내 데스크(앞단 서버)는 살아 있는데, 정작 음식을 만드는 주방(실제 앱)이 대답을 못 해서 빈 접시를 들고 온" 상태입니다.
즉, 앞단은 멀쩡하고 그 뒤의 실제 앱이 죽었거나 응답을 못 하고 있을 가능성이 큽니다.

## 진짜 원인 (아직 확정 아님 — 유력 후보)

지금 제가 가진 정보는 "어제 배포했다"와 "어제부터 502"뿐입니다. 코드도 로그도 보지 못했으므로 **단정하지 않고**, 배포 직후 502가 날 때 가장 흔한 후보를 가능성 순으로 정리합니다.

| 순위 | 유력 후보 | 비유 | 왜 의심되나 |
|:----:|----------|------|------------|
| 1 | **새 앱이 시작하다가 바로 죽음** (실행 오류·환경설정 누락 등) | 주방이 불은 켰는데 가스가 안 들어와 요리를 못 함 | 배포 시점과 장애 시점이 정확히 겹침 |
| 2 | **앞단 서버가 엉뚱한 곳/포트를 바라봄** (배포 중 주소·포트 바뀜) | 안내 데스크가 옮겨간 주방의 새 위치를 모름 | 배포하면서 앱 위치가 바뀌면 흔히 발생 |
| 3 | **앱은 떴지만 시작이 너무 느려 시간 초과** | 주방이 준비 중인데 안내 데스크가 기다리다 포기 | 첫 요청이 느린 앱에서 배포 직후 자주 발생 |

세 후보 모두 "어제 배포"라는 방아쇠와 들어맞습니다. 어느 것인지는 로그를 봐야 갈립니다.

## 어떻게 알아냈나 (근거)

| 확인한 것 | 발견 |
|----------|------|
| 사용자가 알려준 사실 | "배포함" + "어제부터 502" + "사이트" — 이 3가지뿐 |
| 502 오류의 의미 | 앞단 서버가 뒤의 실제 앱에서 정상 응답을 못 받음 (앞단 자체는 살아있음) |
| 배포 시점과 장애 시점 | 둘 다 "어제" — 시간상 겹쳐 배포가 방아쇠일 가능성 높음 |
| 코드·로그·배포 환경 | **아직 못 봄** — 그래서 단정하지 않음 |

> 위 표의 1~3행은 추측이 아니라 주신 정보와 502의 일반적 의미에서 나온 사실입니다. "어느 후보가 진짜인지"는 아래 정보가 있어야 확정됩니다.

## 수정 제안 (아직 적용 안 함)

지금은 원인이 후보 단계라, "고치기" 전에 **원인을 확정하는 확인**을 먼저 권합니다.

1. **(가장 권장) 앱 자체 로그부터 확인** — 배포된 앱이 켜질 때 남긴 기록을 보면 "시작하다 죽었는지(후보 1)" 한 번에 갈립니다. 죽은 흔적이 있으면 거기 적힌 오류 메시지가 진짜 원인입니다.
2. **즉시 응급조치가 필요하면 직전 버전으로 되돌리기(롤백)** — 어제 배포가 방아쇠가 거의 확실하므로, 바로 전에 잘 되던 버전으로 돌리면 사이트는 우선 살아납니다. 원인 분석은 그 뒤에 천천히.

> 적용하려면 알려주세요. 지금은 제안만 한 상태입니다. (이 스킬은 직접 고치지 않습니다 — 고치는 건 `/debug` 담당)

## 아직 모르는 점 (확정에 필요한 정보)

원인을 하나로 좁히려면 아래 중 알 수 있는 것을 알려주세요.

| 필요한 정보 | 왜 필요한가 |
|------------|------------|
| 어디에 배포했나 (예: Vercel, AWS, 직접 서버, 도커 등) | 502를 내는 앞단 서버가 무엇인지 알아야 어디를 볼지 정해짐 |
| 앱 시작 로그 / 배포 로그 | 후보 1(앱이 죽음)인지 바로 확인 가능 |
| 이번 배포에서 무엇이 바뀌었나 (코드만? 환경설정·포트·도메인도?) | 후보 2(주소·포트 어긋남) 판별 |
| **모든** 페이지가 502인가, 일부만인가 | 전부면 앱 전체 다운, 일부면 특정 경로 문제 |
| 앞단 서버 로그의 오류 메시지 (timeout? connection refused?) | "거부됨"이면 후보 1·2, "시간 초과"면 후보 3 |

---
> 한 줄 요약: 어제 배포와 502가 시간상 겹쳐 **배포가 새 앱을 못 띄운 것**이 가장 유력하지만, 코드·로그를 아직 못 봐서 단정은 못 합니다 — 앱 시작 로그와 배포 환경만 알려주시면 바로 좁힐 수 있습니다.
